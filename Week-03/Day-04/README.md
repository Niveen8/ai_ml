# WEEK 03 - Day 04: bTrees, Forests And Support Vector Machines (SVMs) and k-NN
## Overview
The result is a study focusing on the comparison of four distinct supervised machine learning algorithms on the well known IRIS data.
## Models Implemented
* Decision Tree
* Random Forest
* Support Vectory Machine (SVM)
* k-Nearest Neighbours (k-NN)
## Steps Completed
1. Loaded and prepared the Iris dataset.
2. Divided the dataset into training and testing.
3. Trained with four classifiers.
4. All are tested on the same testset FI-score.
5. Comparison of models based on their performance in a table.
6. To HackRF with the Random Forest feature importances.
7. Based on accuracy as our metric to decide the best ventilatory model would be selected by tealning then the result discussed.
## Tools Used
* Python
* Pandas
* Scikit-learn
* Jupyter Notebook
## Outcome
In this project you will learn how to train and test multiple classification models on the same popular dataset that are a breeze to compare and contrast.
