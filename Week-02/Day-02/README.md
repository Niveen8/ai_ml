# Day 2 — Probability distributions

This day focuses on the basics of probability and probability distribution, which are helpful background information for statistics and machine learning.

Be able to name at least the following pd’s: (i) Normal Distribution, (ii) Binomial Distribution, (iii) Uniform Distribution.
